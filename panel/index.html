¿Cómo saco el token? (2 minutos)
  1. Abre github.com → tu foto → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Repository access: Only select repositories → el repo del bot.
  3. Permissions → Repository: Actions = Read and write · Secrets = Read and write · Issues = Read and write (Metadata queda en Read).
  4. Expiración: la que quieras (p. ej. 1 año). Copia el token y pégalo aquí.

🔒 La clave no se guarda en ningún lado: si la olvidas, borras el panel y lo configuras de nuevo.
